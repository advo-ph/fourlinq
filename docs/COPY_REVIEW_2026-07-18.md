# Copy review — proposed wording changes

**For:** Imie / Tita
**Prepared:** 2026-07-18
**Status:** nothing here is live. The site today still says the "now live" wording on every item below.

---

## What this is

A pass was made over the site to remove claims we cannot back with a document. Where a page stated something as fact — a warranty term, a finish count, a performance claim — and we could not point to a brochure, test report, or your written confirmation, the wording was changed to say only what we can prove.

That work is finished and tested, but **it is not published**, because it changes how the site sounds. That is your call, not ours.

## The trade-off, stated plainly

The proposed wording is **more accurate**. It is also **less confident**. "A 10-year limited warranty, written down." becomes "The brochure states a 10-year limited warranty."

Both are defensible. The first sells better. The second cannot be challenged. We do not think this should be decided page-by-page on instinct, so every change is below with both versions side by side.

**You can accept all of it, none of it, or mix.** Each item is independent. Marking "keep live" costs us nothing — the current wording stays.

## How to reply

Fastest is voice or text with the page names, e.g. *"warranty keep live, architects use proposed, inspiration bring back the filters."* You do not need to use this document's format.

## Part 2 — Things that would be removed

These are not rewordings. Content would disappear from the site. We think these need a firmer "yes" than the wording changes do.

### 2.1 Project filters on `/inspiration`

**Now live:** visitors can filter the project gallery by seven categories —
`All projects` · `Casement` · `Sliding` · `Doors` · `Specialist` · `Interior` · `Exterior`

**Proposed:** all seven removed; one ungrouped list of every project.

**Why it was proposed:** the category assigned to each project is not verified — nothing on file confirms a given install is "Casement" rather than "Sliding." Filtering by an unverified label can send someone to the wrong set.

**What it costs:** browsing gets worse. This is the page where someone decides they want what they are seeing.

**Our note:** we would rather **fix the categories than delete the filters**. If you can confirm the operation type for each project, the filters can stay and become accurate. That is a data task, not a code task.

| | |
|---|---|
| **Keep the filters** ☐ | **Remove them** ☐ | **Fix the categories instead** ☐ |

### 2.2 Glass choices in the Design Tool

**Now live:** step 4 shows a grid of glass options a visitor can pick from.

**Proposed:** the grid is replaced by a single note — *"Confirm glass with FourlinQ."*

**Why it was proposed:** we do not have confirmation of which glass types are actually available on which profile, so the tool may let someone choose a combination you cannot supply.

**What it costs:** the tool stops being a full spec and becomes a partial one. The other four steps are unchanged.

| | |
|---|---|
| **Keep the glass choices** ☐ | **Use the confirm-note** ☐ | **Keep, but only the glass we can supply** ☐ |

### 2.3 Architect resources on `/for-architects`

**Now live:** 11 resource entries labelled `PDF` · `DWG` · `RFA`, marked "Available now" or "In progress — Q3 2026".

**Proposed:** 9 entries relabelled `PAGE` · `TERMS` · `DRAWING` · `BIM`, marked "Public page" or "Confirm with FourlinQ".

**Why it was proposed:** the site currently offers CAD and BIM files for download that do not exist. An architect who clicks expecting a DWG gets nothing. You flagged this yourself — the "complete brochure" the page promises is not a real document.

**What it costs:** nothing we can see. This one removes a promise the site cannot keep today.

**Our note:** this is the change we would most recommend accepting.

| | |
|---|---|
| **Keep live** ☐ | **Use proposed** ☐ |

### 2.4 Product specification lists

**Now live:** each product in the catalog drawer lists its specifications (71 spec lines across the catalog).

**Proposed:** roughly half removed (down to 37) — every line we could not trace to the brochure.

**Why it was proposed:** some spec lines have no known source. We could not tell which were measured, which came from a supplier, and which were written as placeholder.

**What it costs:** thinner product pages, which is the opposite of "everything should be complete."

**Our note:** same as the filters — **the better fix is to source the specs, not delete them.** If you confirm the real numbers, they all stay and become defensible. Deleting is the fallback if the numbers cannot be confirmed.

| | |
|---|---|
| **Keep all specs** ☐ | **Remove the unsourced ones** ☐ | **Send us the real numbers** ☐ |
